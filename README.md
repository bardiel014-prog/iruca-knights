# Knights

公開先: https://iruca.tech/knights/

2026-11-24時点の公開版から独立させたソースリポジトリです。リポジトリへのpushだけでは本番は更新されません。

## ローカルで画面を開く

```sh
python -m http.server 8000 --directory public
```

`http://localhost:8000/` を開いてください。このコマンドは画面の確認用で、通信対戦・集計APIは別途必要です。

## 現行版について

公開版の画像参照修正を含みます。フレンド対戦はこの版では未実装です。
