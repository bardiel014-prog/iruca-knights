## 開発中に重視したポイント

ChatGPTとの設計意図の共有と、実践チュートリアルの確認で扱った内容をまとめています。

- **スマートフォン縦持ちを前提にする。** 盤面を指で操作するゲームとして制作しています。操作性を確認するときは、ドラッグ中に指で隠れる範囲、置き先の視認性、ページスクロールとの干渉をスマートフォンで確認する必要があります。
- **連鎖の爽快感と、考えて遊ぶ奥行きを両立する。** ライトな女性向けの遊びやすさを意識し、動かすだけでも合体や連鎖を楽しめて、慣れると盤面と攻守への配分を考えられる方針を共有しました。
- **育てたパネルの使い道を選ぶ。** 宝石の合体で数字を育て、攻めと守りに積む構造です。布陣・覚醒・攻勢・守勢・激突の流れと、相手が守りを積む前に先手が攻撃しないよう、先手初回の攻勢を省く理由をチュートリアルで伝えています。
- **必殺技まで実際の操作で導く。** 説明を読む場面と、光るパネルを操作する場面を設けています。試遊では指定の入れ替えから赤8への合体、必殺技の「眼」の出現まで確認しました。そこでの確認範囲は合体までです。
- **音声を使う理由から商品性を検討する。** 女性向けへの応用と音声を生かした作品づくりを検討する一作として、SE・BGMを含めた手触りを重視しました。キャラクターボイスを追加する際も、行動や反応を聞きたくなる場面との対応が検討点です。
